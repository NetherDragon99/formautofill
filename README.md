# Google Forms Auto-Fill Bookmarklet & Cloud Sync ⚡

أداة متكاملة وسريعة جداً تعمل من شريط المفضلة (Bookmarklet) مباشرة في المتصفح، لتعبئة نماذج Google Forms تلقائياً وبسرعة 0 ملي ثانية مع المزامنة السحابية الذكية عبر Google Apps Script وحل مشاكل عزل النطاقات (Cross-Origin Isolation).

---

## 🌟 الخصائص والمزايا المعمارية (Key Features)

1. **Zero-Delay Local-First (سرعة 0ms)**:
   - تعتمد على الـ `localStorage` المحلي للقراءة الفورية وفتح الفورم بدون أي انتظار للسيرفر.
   - محمية بالكامل من كراش النوافذ المنبثقة (Popup Blockers) عبر فتح النوافذ استجابة مباشرة لنقرة المستخدم أو التنبيه الفوري في حال الحظر.

2. **حل مشكلة تعدد النطاقات (Cross-Origin Sync & Conflict Resolution)**:
   - المتصفحات تعزل `localStorage` لكل موقع منفصل. الأداة تفحص السحابة في الخلفية دائماً.
   - **تنبيه التعارض الفوري**: إذا فُتحت الأداة في موقع يحمل إعدادات محلية قديمة بينما تم تعديل الفورم في السحابة من موقع آخر، تفتح الأداة نافذة عائمة فوراً ببانر تحذيري يخيرك:
     - `⬇️ Apply Cloud`: تنزيل وتحديث الإعدادات المحلية لمطابقة السحابة.
     - `⬆️ Keep Local`: رفع النسخة المحلية الحالية للسحابة واعتمادها.
   - **التشغيل على البارد (Cold Start)**: إذا فُتحت الأداة في موقع جديد تماماً، يظهر لودر سحابي سريع ليسحب الداتا أولاً ويحفظها في الموقع الجديد ثم يفتح الفورم تلقائياً إذا كان الفتح التلقائي مفعلاً.

3. **المزامنة الدقيقة للعداد (Counter Synchronization)**:
   - عداد تفاعلي (`📊 Forms: X`) يدعم التعديل اليدوي بالنقر المباشر أو التصفير (`↺`).
   - عند حدوث تعارض، يتبع العداد بدقة الإجراء الذي تختاره (تنزيل السحابة يطبق عداد السحابة، رفع المحلي يرفع عدادك الحالي).

4. **المصادقة الهجينة والبوكمارك المحمول (Portable Bookmarklet)**:
   - زر `📌 Portable` يقوم بنسخ كود بوكمارك متكامل مدمج به التوكن الخاص بحسابك. يمكنك استخدامه في أي جهاز أو متصفح أو تبويب جديد ليعمل فوراً دون كتابة كلمة المرور مجدداً.

5. **تصميم عصري مرن (Catppuccin Macchiato Theme)**:
   - نافذة عائمة أنيقة قابلة للسحب وتغيير الحجم وسكرول بار مخصص داكن.
   - استخراج تلقائي لأسئلة الفورم وأنواعها (`window.FB_PUBLIC_LOAD_DATA_`) مع تعيين ذكي للحقول (Email, Name, Shift, Gulp, Webviz, Segment ID, Queue, Task Type).

## 🚀 كيفية التثبيت والاستخدام (How to Install & Use)

### الخطوة 1: نسخ كود البوكمارك
1. افتح الملف [`form.js`](file:///b:/Nether%20Dragon/My%20code%20work/bookmarks/form-auto-fill/form.js).
2. انسخ كامل المحتوى (يبدأ بـ `javascript:`).

### الخطوة 2: إضافته إلى شريط الإشارات (Bookmarks Bar)
1. في المتصفح، اضغط كليك يمين على شريط الإشارات واختَر **Add page** أو **إضافة صفحة**.
2. في خانة **Name**: اكتب مثلاً `⚡ Form Runner`.
3. في خانة **URL**: الصق الكود الذي نسخته من `form.js`.
4. اضغط **Save / حفظ**.

### الخطوة 3: ربط نموذج Google Form
1. افتح نموذج Google Form الذي تريد تعبئته تلقائياً في المتصفح.
2. اضغط على البوكمارك `⚡ Form Runner`.
3. ستفتح واجهة الإعدادات ويظهر لك زر `🔗 Link this form`. اضغط عليه لربط النموذج.
4. املأ الإجابات الافتراضية لكل حقل واضغط `💾 Save / Save & Sync`.

## 🛠️ التطوير والبناء (Development & Build)

المشروع منظم بطريقة هندسية تفصل كود المصدر عن كود الإنتاج:

```
form-auto-fill/
├── src/
│   └── bookmarklet.js    <-- كود المصدر النظيف والمنسق والقابل للتطوير
├── build.js              <-- أداة البناء وضغط الكود وفحص الـ Syntax
├── form.js               <-- النسخة المجمعة والمصغرة الجاهزة للاستخدام
├── Code.gs               <-- كود خادم السحابة (Google Apps Script)
└── README.md             <-- هذا الدليل
```

لإعادة بناء وتحديث `form.js` بعد أي تعديل في `src/bookmarklet.js`، قم بتشغيل:
```bash
node build.js
```
يقوم السكريبت بالتأكد من خلو الكود من أي أخطاء برمجية (`new Function() validation`) وتوليد `form.js` المضغوط بحجم مثالي للبوكمارك.

## ☁️ إعداد ونشر خادم السحابة (Google Apps Script Deployment)

إذا رغبت في نشر السيرفر الخاص بك:
1. اذهب إلى [Google Apps Script](https://script.google.com/) وأنشئ مشروعاً جديداً.
2. انسخ محتوى الملف [`Code.gs`](file:///b:/Nether%20Dragon/My%20code%20work/bookmarks/form-auto-fill/Code.gs) وضعه في محرر الأكواد.
3. اضغط على **Deploy** $\rightarrow$ **New deployment**.
4. اختر النوع **Web app**.
5. اضبط الإعدادات كالتالي:
   - **Execute as**: `Me`
   - **Who has access**: `Anyone`
6. انسخ رابط الـ Web App وضعه في متغير `API` في `src/bookmarklet.js` ثم شغّل `node build.js`.
